# Histórias de usuário do Agenda+

## Todos os usuários

1. Como **usuário**, quero **fazer login**, para **acessar as funções do meu perfil**. *(Prioridade: Alta)*

## Paciente

1. Como **paciente**, quero **me cadastrar no sistema**, para **acessar os serviços da
clínica**. *(Prioridade: Alta)*
2. Como **paciente**, quero **ver os horários disponíveis e solicitar um
agendamento**, para **marcar consulta sem ligar para a clínica**. *(Prioridade: Alta)*
3. Como **paciente**, quero **acompanhar o status das minhas solicitações
(pendente, confirmada, recusada)**, para **saber se minha consulta foi aceita**. *(Prioridade: Média)*
4. Como **paciente**, quero **reservar um medicamento anexando a receita quando
necessário**, para **ter certeza de que ele estará disponível**. *(Prioridade: Média)*
5. Como **paciente**, quero **receber notificações sobre minha consulta ou reserva**,
para **não depender de abrir o sistema**. *(Prioridade: Baixa)*

## Secretária

1. Como **secretária**, quero **confirmar ou recusar solicitações com justificativa**,
para **controlar a agenda**. *(Prioridade: Alta)*
2. Como **secretária**, quero **cadastrar, liberar e bloquear horários**, para **que o
paciente veja só o que está disponível**. *(Prioridade: Alta)*
3. Como **secretária**, quero **consultar a agenda de atendimentos por dia**, para
**organizar a recepção**. *(Prioridade: Média)*
4. Como **secretária**, quero **atualizar o estoque e validar receitas**, para **aprovar
ou recusar reservas corretamente**. *(Prioridade: Média)*

## Médico

1. Como **médico**, quero **consultar minha agenda de atendimentos**, para
**organizar minha rotina**. *(Prioridade: Média)*
2. Como **médico**, quero **ver os dados básicos do paciente agendado**, para **me
preparar para o atendimento**. *(Prioridade: Baixa)*

## Administrador

1. Como **administrador**, quero **cadastrar médicos e secretárias**, para **que a
equipe acesse o sistema**. *(Prioridade: Alta)*
2. Como **administrador**, quero **alterar o papel de um usuário**, para **controlar
as permissões de acesso**. *(Prioridade: Média)*
3. Como **administrador**, quero **inativar contas de usuários**, para **impedir o
acesso sem perder o histórico**. *(Prioridade: Média)*
